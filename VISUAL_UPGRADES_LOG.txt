------------------------------------------------------------
FILE: chacha20-cipher/web/scene.js  [NEW COMPONENT]
------------------------------------------------------------
PURPOSE:
Autonomous 3D rendering engine driving the "Living Cryptographic State"
and the "Cryptographic Particle Field".

KEY UPGRADES & FEATURES:
1. 3D State Matrix Geometry:
   - Visualizes the 512-bit ChaCha20 state as a floating 4x4 matrix of 16 glowing nodes.
   - Row-differentiated semantic color coding:
     * Row 0: Constants (Amber glow: #fbbf24)
     * Row 1 & 2: 256-bit Key (Blue/Indigo glow: #60a5fa, #818cf8)
     * Row 3: 32-bit Counter & 96-bit Nonce (Cyan glow: #22d3ee)
   - Orthogonal connecting network lines mapping quarter-round ARX diffusion paths.

2. Cinematic 3D Entrance Sequence (~3.5 Seconds):
   - Stage 1: Dark start (#040711) with solitary central luminous seed particle.
   - Stage 2: 16 particles blossom outward into 4x4 matrix in 3D perspective.
   - Stage 3: Progressive connecting lines materialize between row/col neighbors.
   - Stage 4: 3D perspective initialization rotation (pitch & yaw).
   - Stage 5 & 6: Minimalist badge and typography reveal:
     "CHACHA20 CIPHERFORGE — Interactive ARX Cryptographic Engine".
   - Stage 7: Seamless pushback of the 3D matrix into the background layer while
     the main application UI fades into view.

3. Ambient Particle Field:
   - 320 subtle depth particles with computational drift.
   - 12 ambient floating hexadecimal tokens ('6e2e', '359a', '0f13', etc.) with
     low-contrast opacity and sinusoidal vertical oscillation.
   - Smooth mouse-parallax camera tracking with 0.05 damping factor.
   - Deprecation-free timing using performance.now() elapsed seconds.
   - Automatic CPU/GPU throttling via document visibilitychange listener.
   - Reduced-motion support: skips intro instantly if prefers-reduced-motion is active.
   - Graceful WebGL fallback: falls back to ambient CSS if WebGL is unavailable.
